# bleach-shinigami-poo
Modelo orientado a objetos inspirado en Bleach. Implementa una clase abstracta Shinigami con herencia hacia Capitán, Teniente, Puro, Mestizo y Sustituto. Incluye composición con Zanpakuto y uso de polimorfismo para el cálculo de daño y combate. Proyecto enfocado en práctica de POO en Java.
