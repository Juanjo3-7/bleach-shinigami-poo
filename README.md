## `01` // VISIÓN GENERAL

Proyecto educativo desarrollado para practicar los fundamentos de la programación orientada a objetos en Java utilizando personajes y conceptos inspirados en el universo de Bleach.

El modelo representa diferentes tipos de Shinigami y su relación con las Zanpakuto, aplicando conceptos esenciales para diseñar programas mediante clases y objetos.

## `02` // CONCEPTOS DE PROGRAMACIÓN

| Concepto | Aplicación |
|---|---|
| Abstracción | Definición de una clase base `Shinigami`. |
| Herencia | Especialización de los tipos de personaje. |
| Encapsulación | Organización y control del acceso a los datos. |
| Composición | Relación entre Shinigami y Zanpakuto. |
| Polimorfismo | Comportamientos asociados al combate y al cálculo de daño. |

## `03` // MODELO DEL PROYECTO

Las entidades principales documentadas son:

- `Shinigami`: clase abstracta principal.
- `Capitan` y `Teniente`: categorías de personajes.
- `Puro`, `Mestizo` y `Sustituto`: tipos de Shinigami.
- `Zanpakuto`: elemento asociado al personaje y a sus habilidades.
